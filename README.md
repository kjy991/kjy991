## 🤖 AI-assisted Development

AI를 단순 코드 생성 도구가 아니라 **개발 생산성을 높이는 보조 엔지니어링 도구**로 활용하고 있습니다.

```text
Requirements     → 요구사항 정리 및 누락 검토
Architecture     → 설계 대안 및 기술 검토
Implementation   → 구현 초안 및 반복 작업 보조
Testing          → 테스트 케이스 · Edge Case 점검
Documentation    → API · 배포 · 운영 문서 정리

Final Decision   → 직접 설계 · 검토 · 검증
```
